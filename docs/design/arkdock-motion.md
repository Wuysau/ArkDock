# ArkDock 动效约定

统一曲线 cubic-bezier(0.2, 0.8, 0.2, 1)，CSS token 集中定义。真实事件到达立即提交业务状态。
不播放默认六步演示、不伪造百分比、不为动画延迟发现和首帧。

| 部件 | 触发 | 时长 | 取消与降级 |
| --- | --- | --- | --- |
| 按钮/候选卡 | hover/focus/选中 | 140ms | 背景/边框变化，列表不位移 |
| 边缘提示 | 真实 dockHint | 160ms | hint 消失立即取消；不在目标内容内绘制 DOM |
| 原生吸附 | 原生确认绑定 | 240ms 基线 | 原生层拥有位移；准确跟随优先；未实现缓动不伪称完成 |
| 状态条 | 绑定/识别/失败切换 | 180ms | 稳定高度，旧状态动画被新状态替代 |
| 底部面板 | 打开候选/信任/设置 | 230ms | 16px 上移+淡入；关闭恢复焦点 |
| 原生首帧 | 当前会话第一幅有效帧 | 210ms | 同会话后续更新不重播；新会话清空 |
| 诊断抽屉 | 用户打开 | 210ms | 内容独立滚动；收起立即响应 |
| 识别/构建加载 | 真实任务进行 | 不确定循环 | 任务结束即时消失，不显示虚假进度 |
| 解除 | detach 确认 | 180ms | 立即请求后端，不依赖动画完成 |

减少动画支持“跟随系统 / 减少动画”，取消位移/装饰循环，最多 1ms 淡入。
无动画队列，粒子仅在真实候选拖动及短暂消散期间调度，不按每帧或日志条目触发全屏入场。
动效验收需运行中的 animation/transition、快速切换和 media 断言，静态截图仅用于布局。

识别环只在真实 discovering 存在；首帧动画类在同会话更新时保持不变，避免后续帧中断淡入。
减少动画切换会主动取消已运行过渡；关闭面板在 inert 移除后恢复原触发焦点。
执行中按钮禁用时，当前已激活文档中的模态将焦点回落到面板，不抢其他应用的系统焦点。

新增动效：磁吸候选使用单个原生 alpha-layered Effects 窗口，light/standard/enhanced 分别为 16/24/28 个蓝色粒子，
距离影响强度，离开后 160ms 消散；切换目标/取消/减少动画立即清理。跨窗口粒子不是 WebView DOM。
历史磁吸分支的 Z 序验收发现，普通 HWND_TOP 在拖动时会落在主窗下面；粒子层仅在有效候选与消散期间
临时置顶，隐藏时撤销。位置生产者超过 300ms 未更新时，最多再消散 160ms 后隐藏并停止调度。
Orb 仅在可见时置顶，隐藏/展开后撤销；所有这些表面保留 NOACTIVATE，不抢目标键盘焦点。
水波接到本次真实几何贴附确认后，从贴附侧中点扩散 2–3 道，600ms、100ms 间隔，最多 800ms；
裁剪在整个 main 内，pointer-events:none，既不扭曲原生画面也不改变输入坐标。
同 bindingId 只播放一次，普通移动/缩放及反复状态快照不重播。

Expanded/Orb 的内容淡入与高亮过渡遵循确认状态，不等待 CSS 动画结束才显示可操作表面。
Orb 是真实 58 DIP 轻量表面，透明角落有 native circle region；减少动画不关闭显示功能。
强度 off/light/standard/enhanced，默认 standard，减少动画优先于强度。原生渲染累计帧数与时间
只能用于本轮实际测量，不宣称固定 60 FPS。历史分支验收不代表当前整合版本已完成 Windows GUI 验收。
