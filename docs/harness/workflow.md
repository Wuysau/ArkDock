# 按需工程工作流

从 `AGENTS.md` 按任务路由读取。问答/文案只读来源；小修改最小验证；Bug
先复现定位并增加回归；跨模块改动用短计划，持久取舍用 ADR。
不默认读取整个 docs、开分支、跑全量测试或调用所有 skills。
宿主要求优先；本项目入口不会关闭或覆盖全局指令。

执行前检查目录、Git、用户未提交修改与权限。只改授权项目；工作树可用且
需要隔离时使用。保留来源 worktree 的未提交修改，不擅自提交、stash 或覆盖；不要为了 git commit 绕过权限。

对源码功能用风险驱动测试。每阶段记录真实命令与退出码，区分实现/编译/实测。
可用性由当前环境实测决定；基础、原生与安装门禁分别记录，历史环境阻塞不作为当前结果。
不重复请求已给定产品设计的许可；不可推导安全决策集中询问。

复杂实现记录在 `docs/plans/active/`；验收完成后再归档到 completed。
中断前更新 `docs/status.md`、计划、证据与下一条可执行步骤。
不存储聊天全文、私有推理、账号或敏感日志。

客户端入口机制经官方资料核查：Codex 按目录层级读取项目指令；CLAUDE.md
是 Claude Code 项目记忆入口。其他 Agent 是否读取这些文件须实际核查，
文本扫描只能发现结构风险，不能证明任意客户端的上下文加载行为。
依据见 [来源](../evidence/sources.md)。
