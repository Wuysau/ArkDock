# 通用 MCP 任务交接

ArkDock 通过同一个 ArkDock.exe --mcp 提供工程登记、组件证据、截图、任务领取和结果回报。所有 MCP 客户端使用同一接口，客户端名称仅用于显示，不存在工具品牌白名单。

详细配置、接口和生命周期见 [MCP 接入指南](../runbooks/agent-context-source.md)。

用户在 ArkDock 提交明确修改要求后，Agent 主动领取任务并读取授权证据。每个会话发送一次界面提供的“自动处理提示词”，即可通过 arkdock_wait_for_task 持续等待：提交后领取、读取证据、编辑验证、回报，再等待下一项。客户端停止执行后需重新启动；点击提交不会向聊天输入框写入或唤醒已结束的对话。界面区分等待领取、已领取、Agent 接收、Agent 报告完成、失败、过期和状态未知；报告完成不代表独立代码验收通过。

旧 Channel、App Server、桌面插件、辅助输入框填写和 Node MCP 程序已移除，需要用接入页面生成的单 EXE 配置替换。复制修改要求和导出图片仍可独立使用。

自动化验证覆盖通用客户端协议、真实本机命名管道、OS 客户端身份、不可变图片、上下文和领取隔离、断线/取消/过期以及任务回报。真实客户端的安装、重新加载和 GUI 体验需要单独验收，不用夹具测试代替。
