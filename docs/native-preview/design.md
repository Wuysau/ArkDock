## 方案

继续拆分现有 `src-tauri/src/preview/`，避免复制另一套工作区或 IPC。
新增可独立验证的二进制帧模块和只读依赖报告。SDK 原始 JPEG 在有界邮箱中
保留，元数据与图像分离；原有 PNG 帧契约仅保留为前端集成兼容入口。
新增独立后端验收程序，不依赖另一会话运行中的桌面应用。

先读取并固定官方源码提交，然后对本机合法商业 SDK 单独实验。优先核验
`PreviewBuild` 的专用产物和参数，替换逐保存 `assembleHap` 路径。只在实际
验证重载确认与新画面边界后才复用进程；没有可靠版本边界时采用专用预览
构建后重启，明确状态重置，不能把它称为状态保留热更新。

替代方案：另建 crate 会重复现有会话/信任/调度，不选；直接引入社区 UI、
共享内存或改引擎既超出职责又无测量依据，不选。
